Write to shared state in .context/scratchpad/state.md.

Use this tool to:
- Record important facts discovered during exploration
- Document assumptions being made
- Log decisions for future reference
- Note uncertainties that need resolution
- Set goals and context for coordination

Parameters:
- key: The key name to set
- value: The value to store
- section: (optional) Category - facts, assumptions, decisions, uncertainties, goals, context (default: context)

Best practices:
- Use concise, clear key names
- Choose the appropriate section for the type of information
- Update existing keys rather than creating duplicates
- Remove outdated information when circumstances change

Example usage:
- Set a fact: state_write({ key: "api_version", value: "v2.1", section: "facts" })
- Log a decision: state_write({ key: "auth_method", value: "JWT tokens", section: "decisions" })
- Note uncertainty: state_write({ key: "database_schema", value: "needs review", section: "uncertainties" })
